# FL-001 evidence

Generated by the `faultline` CLI from the commit recorded in each trace's
`provenance.harness_commit`. Do not edit these files by hand; regenerate them.

| path | contents | command |
|---|---|---|
| `run/results.json`, `run/report.md` | 9 SDK targets x 24 scenarios (216 runs) | `faultline run FL-001 -o evidence/fl001/run` |
| `run/traces/*.json` | every wire message, channel and timing, plus provenance | (same) |
| `controls.txt` | harness self-test: 5 mutants + 5 faults + reference | `faultline controls` |
| `random-seed-6/` | the seeded random scenario that was minimised | `faultline run -t py-stdio -s none --random-seed 6 -o ...` |
| `minimized.txt`, `minimized/` | ddmin log, minimal trace, regression test, stdlib reproduction | `faultline minimize random-seed-6/traces/py_stdio__random_seed_6.json -o ...` |

Check a result independently, without MCP Faultline installed:

```sh
pip install mcp==2.3.0
python evidence/fl001/minimized/repro_py_stdio_random_seed_6_min.py python targets/python/server.py stdio
# -> FAIL: request id 9007199254740991 received 0 responses ... RESULT: defect reproduced (exit 1)
```
